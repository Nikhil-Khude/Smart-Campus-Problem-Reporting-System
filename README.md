## 💡 About The Project

A web-based platform that helps students report campus problems and allows administrators to manage, assign, and track them until resolution.

## ✨ Key Features

- 🔐 User Authentication & Role Management
- 📝 Campus Problem Reporting
- 📸 Image Upload
- 🗂️ Problem Categorization & Severity
- 📊 Admin Dashboard
- 🔧 Worker Assignment & Progress Tracking
- ⏱️ Deadline & Overdue Tracking
- 🚨 Problem Escalation
- 📧 Email Notifications
